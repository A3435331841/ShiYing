## 三、已知问题与未完成事项

1. **Chrome 自动读取失败**：Chrome 版本为 157，Windows 上的 Cookie 使用 App-Bound 加密，当前 yt-dlp（2026.08.19）无法解开。已确认与 DPAPI 报错是同一问题。不要尝试调用系统服务或注入 Chrome 取密钥，那是绕过安全机制。
2. **扩展无法在用户的 Chrome 中显示**：需要先确认用户用的是哪个浏览器、是否能打开 `chrome://extensions`、加载时选的是否是 `yuanbao-login-copy` 文件夹本身。注意：自动模式下的诊断命令曾因读取 Chrome Cookie 被拦截，所以不要再运行读取 Chrome Cookie 的命令。
3. **真实下载未验证**：没有可用的 Cookie，无法确认 `A2uumghDtJ` 的 `feedInfo` 里是否有 `shortUri`，也无法确认是否存在音频流。
4. **批次 D 已完成**：`tests/test_wechat_capture_safety.py::test_preview_then_selected_start_for_wechat` 已覆盖 `/api/preview`、`/api/jobs` 创建、`/api/jobs/{id}/start` 传入 `item_ids`，并断言只有选中的项完成。下载与校验已在测试中打桩，不触网。测试通过。
5. **界面说明过于技术化**：手动保存 Cookie 的步骤对普通用户太难。目标是让用户不需要理解 Cookie。
6. **剪贴板安全**：复制后剪贴板会暂存登录态，文档中应提醒用户粘贴后清空剪贴板。
