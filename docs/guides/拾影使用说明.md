# 拾影 · 本地视频下载工具

安装目录：拾影所在的文件夹（下文记作「安装目录」）。默认下载目录：安装目录下的 `downloads` 子文件夹，可在「设置」中更改。

## 启动与关闭

- 双击桌面「拾影」，或双击本目录中的「启动拾影.bat」。
- 正常情况下打开独立桌面窗口；如果本机 WebView2 无法启动，将在默认浏览器打开本地页面。
- 关闭窗口后，已经创建的下载任务会继续在本机后台执行。完全退出时，先关闭窗口，再运行「停止拾影.bat」。
- 本地页面地址是 `http://127.0.0.1:8766`，仅监听本机，不需要注册工具账号。桌面窗口、`start.bat` 与浏览器打开的是同一个服务。

## 下载

1. 复制一条视频或图文作品分享链接，也可以复制整段分享文案。
2. 粘贴到首页，点击「解析并下载」，或按 Ctrl+Enter。
3. 在任务列表查看真实状态、下载字节和速度。没有总大小时不会显示虚构的百分比。
4. 完成后点击「打开文件夹」。点击任务标题可查看错误详情和实际保存文件。

重复链接会先提示已有任务，可以「跳过这些链接」或「仍然下载」，不会静默建两份任务。列表支持按标题、作者或平台搜索；设置中可以看到缓存大小并清理，正在下载时不会允许清理。

侧栏三个入口按使用意图分层：「收集」（粘贴链接）、「进度」（进行中与需处理的任务）、「资料库」（已完成的本地内容，以缩略图网格呈现）。「进度」页可用「全部未完成 / 进行中 / 已暂停 / 需处理」筛选；「资料库」可按类型与平台筛选、按最近完成或标题排序。首页显示最近 6 个匹配任务，点击「下载任务」查看完整记录；已有任务时添加区会自动收起为紧凑条，可点「展开引导」还原。活动任务支持取消；部分完成任务可保留成功文件并重试失败项。已中断任务会重新创建下载。

粘贴多条链接时，输入区会实时显示「识别到 N 条 / 重复 N 条 / 无法识别 N 条」。无法识别只统计链接本身的问题（不支持的平台或畸形链接）并列出样例；分享文案中的普通文字不计入。一次最多 50 条。当前视图、筛选条件与输入草稿会保留在本机，刷新页面后不会丢失。

## AI 搜索

不确定作品链接时，可以在首页点击「AI 搜索」：输入想找的内容描述（例如「一只橘猫趴在键盘上睡觉的短视频」），或粘贴图片链接/上传本地图片，选择平台后搜索候选作品，勾选后直接创建下载任务。

- 平台范围：B站、YouTube、小红书、抖音、快手可以搜索；抖音精选没有独立搜索入口、视频号没有公开搜索接口，界面中会置灰并说明，请粘贴链接下载。
- AI 理解层（可选）：在「设置 → AI 搜索」中填写 Agnes 的 API Key（免费模型 `agnes-3.0-flash`，OpenAI 兼容，也可换成任意兼容地址与模型）。Key 使用 Windows 用户账户保护加密保存在本机，不会回显。未配置 Key 时可勾选「跳过 AI，直接关键词」照常搜索。
- 登录要求：**抖音、快手、小红书搜索需要登录态**（实测匿名搜索会被验证码中间页、风控码 result=2、安全限制分别拦截）。在「设置 → AI 搜索 → 搜索登录态」点对应平台的登录按钮，在弹出的窗口里扫码登录一次即可；登录态保存在本机专用浏览器 Profile 中，之后搜索直接复用，不需要每次开 Chrome。小红书在已安装 Agent-Reach 时还可免登录走它的公开搜索。B站公开搜索无需登录，触发风控时稍后再试。
- 平台接口细节：快手网页搜索走 `/rest/v/search/feed`，抖音搜索由页面自身完成签名；拾影只读取页面返回的结果，不逆向签名算法。
- 可选增强：若本机已安装 Agent-Reach（MIT，独立开源项目），B站/YouTube/小红书会优先走它的渠道；未安装不影响使用。
- 搜索只读：不点赞、不评论、不私信；只在你主动点击时发起。搜索结果与平台一致，受登录、风控与平台改版影响。

## 保存位置和登录态

在「设置」中更改目录。桌面窗口支持原生文件夹选择，也可手动填写绝对路径。设置只影响新任务；旧任务保留原目录与登录态配置。文件按平台、作者归档。

公开内容默认不读取浏览器 Cookie。遇到需要登录的作品，可开启「使用 Chrome 登录态」，先在 Chrome 登录，再完全退出 Chrome 后新建任务。Chrome 占用、Cookie 加密与站点验证都可能导致读取失败，程序会显示具体原因。可填写 Chrome 个人资料文件夹，如 Default 或 Profile 1。

重试旧任务通常保留原有配置。Cookie 读取失败时，主页的「重试」会按当前设置重新创建任务。

## 平台实际范围

- B站：已完成过真实视频下载与音视频校验；当前账号和平台权限会影响可用画质。
- 抖音、抖音精选：已接入抖音解析器，支持分享文案识别；用户提供的抖音图文样例当前需要登录，精选独有内容尚未独立实测。
- 快手、小红书：已接入上游解析器，尚未在本机完成有效作品的下载验收。
- 视频号：只使用你自己的腾讯元宝登录态。最简单的办法：打开「设置 → 登录态 → 视频号登录态」，点「**扫码登录元宝**」，在弹出的浏览器窗口里扫码或登录，登录态会自动加密保存（Windows 用户账户保护，可清除），无需手动复制。备选方式：在 Chrome 中加载 `extension/yuanbao-login-copy` 文件夹作为扩展（「扩展程序」→ 开启开发者模式 → 加载已解压的扩展程序），先登录元宝，点扩展图标 →「复制元宝登录态」，再回到设置粘贴保存。程序不绕过登录，不共享 Cookie，也不修改解密流程。没有嵌入第三方账号，不使用公共在线解析服务。图集、直播回放等非视频作品暂不支持，会得到明确提示。微信客户端播放抓取通道暂未启用，尚未完成真实客户端验收。

平台已接入不等于所有链接均可下载；登录、私密、删除、风控和平台变化会影响结果。仅保存你有权下载的内容。

## 当前版本与数据

本版专注下载，不包含字幕、转写、AI 总结等后续处理。

代码、依赖环境、任务记录和窗口数据都保存在安装目录内。源码方式依赖现有 Windows Python 运行时、WebView2 和 FFmpeg，复制到其他电脑后需要安装运行环境；重新安装依赖可运行「安装依赖.bat」（需要已安装 uv）。打包版（便携包 zip / 安装程序）自带 FFmpeg 与 Deno，无需安装 Python，仍需系统已有 Google Chrome 与 WebView2 运行时。

`data/state` 为任务记录；`data/config.json` 为设置；`data/webview` 为桌面窗口数据；视频号 Cookie 单独保存在 `data/yuanbao-cookie.txt`，不会展示回页面。分享源码时不要包含 data、downloads 或 .venv。

分段下载缓存位于安装目录下的 `cache` 子文件夹，每次传输只有一层缓存编号目录。完成后自动清理，失败或取消时保留可续传文件。已完成视频仍按平台、作者归档。

抖音单个公开作品默认尝试游客会话，不读取 Chrome Cookie；平台仍可能要求登录或暂时限制访问。游客模式只能选择当前公开会话返回的可用素材。
