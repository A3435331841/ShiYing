# 发布前最小验收清单（v0.3.1）

> 口径：每项必须由维护者本人以真实账号、真实网络、真实文件执行并记录结果；
> 自动化测试通过不能替代本清单。任何一项失败即阻断发布，或在 README 支持矩阵中
> 如实降级对应声明。历史依据：[完整修复推进记录](../完整修复推进记录.md)、
> [平台覆盖实测报告](平台覆盖实测报告.md)、
> [UI 审计报告](../审计产物/UI设计审计-2026-11-10/UI审美与设计审计报告.md)。

## 一、安装与入口（全新目录可复现）

- [ ] 全新空目录按 README 唯一安装说明完成安装并启动，环境检查失败时给出可执行提示（含 FFmpeg/Chrome 缺失场景）。
- [ ] 已有服务运行时重复启动，打开的是同一实例；「停止拾影」只停止本实例，不误伤其他进程。
- [ ] 桌面壳（pywebview）与浏览器入口展示的 build 指纹一致；修改任意被指纹覆盖的文件后指纹变化。

## 二、创建与执行（真实用户主路径）

- [ ] 单条链接、批量（多条）、无效链接、重复链接四类输入都得到明确结果；重复弹窗的「跳过/仍然下载」行为正确。
- [ ] 预览选集：三集只选第二集，仅第二集进入下载，任务完成后显示「所选 1/1 已完成」而非「部分完成」；全部不选不可启动。
- [ ] 下载中暂停 → 继续：当前文件从中断处继续而非跳过；各平台的断点续传分别验证一次。
- [ ] 取消、断网重试、进程强退后重启：任务状态与已完成文件保持正确。
- [ ] 登录类操作（扫码登录元宝、Chrome 验证）超过 20 秒不中断，等待期间可取消且不遗留浏览器窗口。

## 三、平台真实验收（把 ⚠️ 变 ✅ 或诚实降级）

每个平台至少两个样本：一个公开单作品 + 一个主页/列表；记录日期、登录状态、
作品类型、保存文件与校验结果到 [平台覆盖实测报告](平台覆盖实测报告.md)。

- [ ] **视频号**：真实元宝登录态保存后，下载普通视频作品两例（含一例 >100MB）；验证 h264/h265 嵌套字段解析与 FFprobe 校验通过。失败样本同时记录 issue_code 是否不再是 unknown。
- [ ] **快手**：单视频两例 + 作者主页分页一例；验证「末页不明确」标记与图集校验；记录竖向长图仍为切片的限制。
- [ ] **抖音主页**：实验性声明下至少一例主页发现 + 下载；记录 SecSDK 签名失败时的回退行为。
- [ ] **小红书**：混合内容（图文/视频/Live Photo）各一例，覆盖「暂时无法打开这篇笔记」的过期链接路径，确认显示「不可用」且不提供重试按钮。
- [ ] **B站 / YouTube**：高画质需合并的样本各一例（验证 FFmpeg remux）。

## 四、失败可解释性（v0.3.1 新增分类的线上确认）

- [ ] 重启服务后打开「需处理」视图：历史 unknown 任务已显示具体类别（不可用/已拦截/网络异常/Cookie 异常/响应异常），不再出现「任务执行遇到异常」兜底文案（除真正未归类的新样本）。
- [ ] 对每个新类别抽查一个任务：界面「发生了什么/解决办法」双段文案与实际原因相符。

## 五、数据与安全

- [ ] 历史清理只删记录不删文件；缓存清理不触碰活动/暂停任务。
- [ ] `data/`、`downloads/`、`*.pem`、`*.crx` 不进入 git（`git status` 验证）；`data/certs/` 已不存在，私钥留档于 `backups/certs-retired-2026-11-10/`（不上传、不入库）。
- [ ] 发布包（`scripts/package_release.py` 产物）清单不含凭据、运行数据、个人媒体与私钥；SHA256SUMS 可复验。

## 六、UI 复验（按审计报告同方法）

- [ ] 深浅主题下已启用主按钮默认/悬停/聚焦对比度 ≥4.5:1（v0.3.1 复测：暗色 4.50、暗色悬停 5.46、浅色 4.84、浅色悬停 6.06，已达标）。
- [ ] 输入提示对比度 ≥4.5:1（v0.3.1 复测：浅色 5.14，占位符不再叠 0.85 透明度，已达标）。
- [ ] 断点边界实测并记录：1039/1040/1041/1042 与 1219/1220/1221/1222px。**已知残留**：1220→1221px 标题列收窄约 150px（基础网格重新引入 size 列 112px 与更大 gap）；1040→1041px 侧栏由 76px 图标栏展开为 240px，标题列收窄约 164px（单因素切换，无工具栏同时恶化）。是否重构 size 列（移入元信息行）由本轮实测后决策，不与本清单其他项绑定。
- [ ] 740×620 CSS 视口、系统缩放 125%/150%、连续进度更新下键盘焦点不丢失。
